# Implementierungsberichte

Hier entstehen `P0.md`, `P1.md`, `P2.md`, `P3.md` und `P4.md` auf Grundlage der [Phasenberichtvorlage](../templates/PHASENBERICHT.template.md). Sie beschreiben ausgeführte Arbeit, keine zukünftigen Testerfolge.

Kleine bereinigte Belege: `evidence/<phase>/<run-id>/`. Secrets und rohe Logs bleiben ausserhalb von `docs/` in ignorierten oder temporären Laufzeitpfaden.

Berichte vor dem Handoff mit dem Produktstand festschreiben. Reviewer verändern sie nicht. Frühere Aussagen nicht rückwirkend an einen korrigierten Kandidaten anpassen; Korrekturen nachvollziehbar ergänzen und neuen Kandidaten erstellen. Der vollständige Vertrag steht in [Abschnitt 8 des Auftrags](../AUFTRAG_GRUNDINSTALLATION.md#8-handoff-und-unabhängiges-review).
